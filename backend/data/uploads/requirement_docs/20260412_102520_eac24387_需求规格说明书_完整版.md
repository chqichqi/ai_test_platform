#### 3.1.3 核心业务逻辑

**1. 项目创建流程**
```
用户填写项目信息
    │
    ▼
后端校验项目编码唯一性（包括已删除项目）
    │
    ├── 编码已存在 ────────▶ 返回错误提示
    │
    ▼
创建项目记录 + 创建默认版本
    │
    ▼
将创建者设为项目负责人
    │
    ▼
创建成功，跳转到项目详情页
```

**2. 版本状态流转**
```
PLANNING ──────▶ DEVELOPING ──────▶ TESTING ──────▶ FROZEN ──────▶ RELEASED
   │                  │                │              │              │
   │                  │                │              │              │
   ▼                  ▼                ▼              ▼              ▼
  规划中            开发中            测试中          冻结中         已发布

流转规则：
- PLANNING → DEVELOPING：开始开发
- DEVELOPING → TESTING：提测
- TESTING → FROZEN：测试通过，准备发布
- FROZEN → RELEASED：正式发布
- RELEASED → ARCHIVED：归档（可选）
```

#### 3.3.2 需求→用例业务流程

```
需求文档导入
    │
    ▼
AI解析文档，提取结构化内容
    │
    ▼
生成测试点思维导图（XMind格式）
    │
    ▼
用户编辑调整测试点结构
    │
    ▼
AI根据测试点生成测试用例
    │
    ├────────────────────────────────────────┐
    ▼                                        ▼
生成功能测试用例                      生成WebUI/API用例
    │                                        │
    ▼                                        ▼
用例审核                                  元素定位器识别
    │                                        │
    ▼                                        ▼
审核通过                                  定位器验证
    │                                        │
    ▼                                        ▼
加入用例库                                加入测试库
```

#### 3.3.3 用例生成逻辑

```
AI生成测试用例流程

输入：测试点描述 + 项目上下文
    │
    ▼
AI分析测试点
    │
    ├── 识别测试类型（功能/UI/API/性能）
    ├── 识别业务场景
    └── 识别关键数据字段
    │
    ▼
生成测试场景
    │
    ├── 正常场景（Happy Path）
    ├── 异常场景（Error Handling）
    └── 边界场景（Boundary Value）
    │
    ▼
生成测试用例详情
    │
    ├── 用例标题
    ├── 前置条件
    ├── 测试步骤
    ├── 预期结果
    ├── 测试数据
    └── 优先级（P0/P1/P2/P3）
    │
    ▼
返回结构化用例数据
```

### 3.16 SKILL管理模块

#### 3.16.1 功能概述

**模块定位：**
SKILL管理模块是AI驱动测试的核心能力支撑模块，通过预定义的测试技能（SKILL）规范AI生成测试用例的行为和质量标准，实现测试用例生成的标准化、专业化和可定制化。

**核心价值：**
1. **标准化生成**：确保所有AI生成的测试用例符合统一格式和规范
2. **知识沉淀**：将测试专家的经验和方法论固化到SKILL中
3. **质量可控**：通过SKILL约束AI生成过程，提升用例质量
4. **灵活定制**：不同项目、不同团队可使用不同的SKILL
5. **持续优化**：通过使用反馈不断优化SKILL效果

**应用场景：**
```
场景1：新项目初始化
项目创建 → 选择或创建SKILL → AI根据SKILL生成符合项目规范的测试用例

场景2：测试规范统一
制定团队SKILL → 所有成员使用统一SKILL → 确保用例风格和质量一致

场景3：领域专业化
电商项目使用电商SKILL → 自动包含价格计算、库存扣减等电商特有测试点

场景4：SKILL版本迭代
收集用例质量反馈 → 优化SKILL内容 → 升级SKILL版本 → 重新生成更优质用例
```

##### 3.16.2.3 SKILL效果评估与优化

**功能清单：**

| 功能点 | 功能描述 | 评估维度 |
|--------|---------|---------|
| 用例质量评分 | 对生成用例进行打分 | 完整性、准确性、可读性 |
| 覆盖率分析 | 分析测试覆盖程度 | 功能覆盖、场景覆盖 |
| 效率统计 | 统计生成效率 | Token消耗、耗时、生成数量 |

| 优化建议 | AI给出SKILL优化建议 | Prompt优化、示例补充 |
| A/B测试 | 对比SKILL版本效果 | 控制变量对比 |

**评估指标体系：**

```
SKILL效果评估指标

一、生成质量指标
├─ 完整性 Score (0-100)
│  ├─ 字段完整性：必填字段是否都有值
│  ├─ 场景完整性：正常/异常/边界场景是否都覆盖
│  └─ 数据完整性：测试数据是否具体有效
│
├─ 准确性 Score (0-100)
│  ├─ 预期结果可验证性
│  ├─ 测试步骤可执行性
│  └─ 业务逻辑正确性
│
└─ 可读性 Score (0-100)
   ├─ 标题简洁明了度
   ├─ 步骤描述清晰度
   └─ 整体逻辑连贯性

二、生成效率指标
├─ 平均生成时间（秒）
├─ 平均Token消耗
```

```sql
-- SKILL模板表
CREATE TABLE test_skills (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    
    -- 基本信息

    code VARCHAR(50) UNIQUE NOT NULL COMMENT 'SKILL编码',
    description TEXT COMMENT 'SKILL描述',
    skill_type VARCHAR(50) NOT NULL COMMENT 'SKILL类型: functional/api/ui/performance/security',
    
    -- 版本控制
    version VARCHAR(20) NOT NULL DEFAULT '1.0.0' COMMENT 'SKILL版本号',
    is_latest BOOLEAN DEFAULT TRUE COMMENT '是否最新版本',
    parent_skill_id BIGINT COMMENT '父SKILL ID（用于版本继承）',
    
    -- 归属信息
    project_id BIGINT COMMENT '所属项目（NULL表示全局SKILL）',
    is_global BOOLEAN DEFAULT FALSE COMMENT '是否全局SKILL',
    is_default BOOLEAN DEFAULT FALSE COMMENT '是否为项目默认SKILL',
    
    -- SKILL内容（JSON格式）
    content JSON NOT NULL COMMENT 'SKILL完整内容',
    -- content结构：
    -- {
    --   "role": {角色定义},
    --   "input": {输入定义},
    --   "output": {输出规范},
    --   "methods": [测试方法库],
    --   "domain_rules": {领域规则},
    --   "quality_checks": [质量检查],
    --   "examples": [示例库],
    --   "prompt_template": "提示词模板"
    -- }
    
    -- 统计信息
    usage_count INTEGER DEFAULT 0 COMMENT '使用次数',
    generation_count INTEGER DEFAULT 0 COMMENT '生成次数',
    avg_quality_score FLOAT COMMENT '平均质量评分',
    
    -- 状态
    status VARCHAR(20) DEFAULT 'active' COMMENT '状态: active/draft/deprecated',
    
    -- 创建信息
    created_by BIGINT COMMENT '创建人',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    INDEX idx_skill_type (skill_type),
    INDEX idx_project_id (project_id),
    INDEX idx_status (status),
    INDEX idx_is_global (is_global),
    INDEX idx_is_default (is_default),
    
    FOREIGN KEY (project_id) REFERENCES projects(id),
    FOREIGN KEY (parent_skill_id) REFERENCES test_skills(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='SKILL模板表';

-- SKILL使用记录表
CREATE TABLE skill_usage_logs (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    
    skill_id BIGINT NOT NULL COMMENT '使用的SKILL ID',
    version_id BIGINT COMMENT '关联的版本ID',
    project_id BIGINT COMMENT '关联的项目ID',
    
    -- 生成信息
    input_tokens INTEGER COMMENT '输入Token数',
    output_tokens INTEGER COMMENT '输出Token数',
    generation_time_ms INTEGER COMMENT '生成耗时(毫秒)',
    generated_count INTEGER COMMENT '生成用例数',
    
    -- 质量评估
    quality_score FLOAT COMMENT '质量评分',
    completeness_score FLOAT COMMENT '完整性评分',
    accuracy_score FLOAT COMMENT '准确性评分',
    readability_score FLOAT COMMENT '可读性评分',
    
    -- 用户反馈
    user_feedback TEXT COMMENT '用户反馈',
    user_rating INTEGER COMMENT '用户评分(1-5)',
    
    created_by BIGINT COMMENT '使用人',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '使用时间',
    
    INDEX idx_skill_id (skill_id),
    INDEX idx_version_id (version_id),
    INDEX idx_project_id (project_id),
    INDEX idx_created_at (created_at),
    
    FOREIGN KEY (skill_id) REFERENCES test_skills(id),
    FOREIGN KEY (version_id) REFERENCES versions(id),
    FOREIGN KEY (project_id) REFERENCES projects(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='SKILL使用记录表';

-- SKILL示例库表
CREATE TABLE skill_examples (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    
    skill_id BIGINT NOT NULL COMMENT '所属SKILL ID',
    
    name VARCHAR(200) COMMENT '示例名称',
    description TEXT COMMENT '示例描述',
    
    input_example TEXT NOT NULL COMMENT '输入示例',
    output_example JSON NOT NULL COMMENT '输出示例',
    
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否启用',
    sort_order INTEGER DEFAULT 0 COMMENT '排序',
    
    created_by BIGINT COMMENT '创建人',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    
    INDEX idx_skill_id (skill_id),
    INDEX idx_is_active (is_active),
    
    FOREIGN KEY (skill_id) REFERENCES test_skills(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='SKILL示例库表';

-- 项目SKILL关联表（项目使用哪些SKILL）
CREATE TABLE project_skills (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    
    project_id BIGINT NOT NULL COMMENT '项目ID',
    skill_id BIGINT NOT NULL COMMENT 'SKILL ID',
    
    is_default BOOLEAN DEFAULT FALSE COMMENT '是否为默认SKILL',
    usage_order INTEGER DEFAULT 0 COMMENT '使用排序',
    
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    
    UNIQUE KEY uk_project_skill (project_id, skill_id),
    INDEX idx_project_id (project_id),
    INDEX idx_skill_id (skill_id),
    
    FOREIGN KEY (project_id) REFERENCES projects(id),
    FOREIGN KEY (skill_id) REFERENCES test_skills(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='项目SKILL关联表';
```
