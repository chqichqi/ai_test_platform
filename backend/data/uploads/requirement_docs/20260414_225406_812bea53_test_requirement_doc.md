## 2. 功能需求详细说明

### 2.1 登录功能

#### 2.1.1 功能描述
用户通过登录页面输入账号和密码，验证成功后进入系统首页。

#### 2.1.2 页面元素
| 元素类型 | 名称 | 必填 | 说明 |
|---------|------|------|------|
| 输入框 | 手机号/账号 | 是 | 11 位数字 |
| 输入框 | 密码 | 是 | 6-20 位字符 |
| 按钮 | 登录按钮 | - | 提交登录 |
| 按钮 | 注册按钮 | - | 跳转到注册页面 |
| 链接 | 忘记密码 | - | 跳转到密码找回页面 |

#### 2.1.3 业务规则
1. 手机号必须为 11 位数字
2. 密码长度 6-20 位字符
3. 连续输入错误 5 次后锁定账号 30 分钟
4. 登录成功后跳转到系统首页
5. 点击注册按钮跳转到注册页面

#### 2.1.4 测试用例

**测试用例 1：正常登录**
- 前置条件：用户已注册
- 测试步骤：
  1. 打开登录页面
  2. 输入正确的手机号：13800138000
  3. 输入正确的密码：123456
  4. 点击登录按钮
- 预期结果：登录成功，跳转到系统首页

**测试用例 2：手机号格式错误**
- 前置条件：无
- 测试步骤：
  1. 打开登录页面
  2. 输入错误的手机号：1380013（不足 11 位）
  3. 输入密码：123456
  4. 点击登录按钮
- 预期结果：提示"请输入正确的 11 位手机号"

**测试用例 3：密码长度错误**
- 前置条件：无
- 测试步骤：
  1. 打开登录页面
  2. 输入正确的手机号：13800138000
  3. 输入错误的密码：123（不足 6 位）
  4. 点击登录按钮
- 预期结果：提示"密码长度应为 6-20 位字符"

**测试用例 4：账号锁定**
- 前置条件：用户账号存在
- 测试步骤：
  1. 打开登录页面
  2. 输入正确的手机号
  3. 连续输入错误密码 5 次
  4. 第 6 次尝试登录
- 预期结果：提示"账号已锁定，请 30 分钟后再试"

**测试用例 5：跳转到注册页面**
- 前置条件：无
- 测试步骤：
  1. 打开登录页面
  2. 点击"注册"按钮
- 预期结果：跳转到注册页面

### 2.2 注册功能

#### 2.2.1 功能描述
新用户通过手机号验证码方式进行注册。

#### 2.2.2 页面元素
| 元素类型 | 名称 | 必填 | 说明 |
|---------|------|------|------|
| 输入框 | 手机号输入框 | 是 | 11 位数字 |
| 输入框 | 验证码输入框 | 是 | 6 位数字验证码 |
| 按钮 | 获取验证码按钮 | - | 发送短信验证码 |
| 按钮 | 注册按钮 | - | 提交注册 |
| 按钮 | 取消按钮 | - | 返回登录页面 |
| 按钮 | 登录按钮 | - | 返回登录页面 |

#### 2.2.3 业务规则
1. 手机号必须为 11 位数字
2. 验证码为 6 位数字，有效期 5 分钟
3. 获取验证码后 60 秒内不能重复获取
4. 注册成功后自动跳转到登录页面
5. 点击取消按钮返回登录页面
6. 已注册的手机号不能重复注册

#### 2.2.4 测试用例

## 4. 非功能需求

### 4.1 性能要求
- 页面加载时间 < 2 秒
- 登录响应时间 < 1 秒
- 验证码发送时间 < 5 秒

### 4.2 安全要求
- 密码传输加密（HTTPS）
- 密码存储加密（BCrypt）
- 防止暴力破解（错误 5 次锁定）
- 验证码防刷（60 秒间隔）

### 4.3 兼容性要求
- 支持 Chrome、Firefox、Edge 浏览器
- 支持移动端响应式布局
