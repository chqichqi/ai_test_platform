# Phase 22改进：知识图谱完整功能 - 测试步骤和验证清单

## 一、环境准备

### 1.1 后端环境

```bash
# 进入后端目录
cd backend

# 安装Playwright（用于系统探索）
pip install playwright
playwright install chromium

# 启动后端服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 1.2 前端环境

```bash
# 进入前端目录
cd frontend

# 安装依赖（如果需要）
npm install

# 启动前端服务
npm run dev
```

### 1.3 数据库准备

```bash
# 初始化数据库（首次运行）
cd backend
python -c "from app.core.database import init_db; init_db()"
```

### 1.4 测试环境准备

需要一个可测试的Web应用：
- **测试目标**：提供URL和登录账号
- **建议使用**：本平台自身（http://localhost:5173 或 http://localhost:8000/docs）
- **登录账号**：管理员账号（admin / admin123）

## 二、功能测试步骤

### 2.1 创建项目版本

**步骤**：
1. 打开浏览器访问 http://localhost:5173
2. 登录系统（用户名：admin，密码：admin123）
3. 进入"项目管理"页面
4. 点击"创建项目"按钮
5. 填写项目信息：
   - 项目名称：测试项目
   - 项目编码：TEST001
   - 描述：用于测试知识图谱功能
6. 点击"确定"创建项目
7. 进入项目详情页
8. 点击"创建版本"按钮
9. 填写版本信息：
   - 版本号：v1.0.0
   - 版本名称：第一版
   - 计划开始时间：选择日期
   - 计划结束时间：选择日期
10. 点击"确定"创建版本

**验证点**：
- ✅ 项目创建成功
- ✅ 版本创建成功
- ✅ 版本列表显示新版本
- ✅ 版本状态为"规划中"

---

### 2.2 触发知识图谱生成

**步骤**：
1. 在版本列表操作栏找到"生成知识图谱"按钮（蓝色图标）
2. 点击按钮，弹出配置弹窗
3. 填写配置信息：
   - **项目基础URL**：http://localhost:5173
   - **登录用户名**：admin
   - **登录密码**：admin123
   - **爬取策略**：选择"normal"（5-10分钟）
   - **跳过租户机构**：勾选（默认）
4. 点击"开始生成"按钮

**验证点**：
- ✅ 弹窗正确显示配置表单
- ✅ 表单验证正常（URL格式、必填字段）
- ✅ 点击按钮后弹窗关闭
- ✅ 进度弹窗自动打开

---

### 2.3 观察生成进度

**验证点**：
- ✅ 页面正常加载
- ✅ 力导向图正确显示
- ✅ 节点可拖动
- ✅ 搜索功能正常（节点高亮）
- ✅ 统计信息正确显示

## 四、常见问题排查

### 4.1 Playwright未安装

**错误提示**：
```
Playwright not installed
```

**解决方案**：
```bash
pip install playwright
playwright install chromium
```

### 4.2 登录失败

**错误提示**：
```
登录表单未找到
```

**排查步骤**：
1. 检查URL是否正确
2. 检查用户名密码是否正确
3. 手动访问URL查看登录表单结构
4. 检查登录按钮选择器是否匹配

### 4.3 进度不更新

**排查步骤**：
1. 检查后端日志是否有错误
2. 检查数据库是否有记录
3. 检查前端是否正确轮询进度API
4. 检查graph_id是否正确传递

### 4.4 节点未显示

**排查步骤**：
1. 检查API返回的数据是否完整
2. 检查nodes数组是否正确构建
3. 检查D3力导向图是否正确绘制
4. 检查SVG容器是否正确渲染
